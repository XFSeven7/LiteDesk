# 单进程隐藏后内存压缩实验（2026-11-01）

约束：保持一个应用进程、隐藏后的自动收纳及当前系统图标体验。优先在临时源码快照中做实验，再修改正式代码；未把会增加占用的试验加入产品。

## 已修复的引用问题

SHGetImageList 返回的 IImageList 接口引用此前未配对 Release。新增资源回归测试在自身持有 COM 初始化和一个独立图标接口引用时，比较创建/销毁列表前后的系统接口引用计数：

- 修复前连续三次 before/after 分别为 4/4、5/5、6/6；测试退出码 4。
- 修复后连续三次均为 4/3；测试退出码 0。

正式实现记录通过 SHGetImageList 获取的引用，在列表控件全部销毁后、CoUninitialize 前释放。通过 SHGetFileInfo 得到的借用图标表不执行 ImageList_Destroy，也不错误转换成拥有的接口。

这个修复保证引用配对，但不代表 Windows 的进程级图标缓存会被释放，不能把接口计数减少当成 MiB 级内存节省。

## 完整 App 合成负载初筛

同机 Windows x64 / MSVC Release，1000 条合成 txt 文件，三次整理/隐藏循环，隐藏后空闲 1.5 秒采样；每种方案单轮初筛的专用内存如下。数据单位 KiB。

| 方案 | 隐藏后专用内存 |
|---|---:|
| 当前基线 | 4424 |
| 配对释放图标引用 | 4384 |
| 再请求 COM 回收闲置库 | 4376 |
| 再延迟加载并卸载 Shell32 导入引用 | 5188 |
| 再请求堆资源优化和整理 | 4768 |

几十 KiB 的差异可能包含进程初始化波动。COM 回收没有明显增加收益；显式 DLL 卸载和堆组合反而更高，均未采用。尤其没有强制 FreeLibrary 释放系统仍在使用的模块，也没有使用 CoFreeUnusedLibrariesEx(0,0) 绕过组件清理等待。

初筛源码、构建与数据在 build/hidden-research/ 下，正式代码不含 HIDDEN_VARIANT 分支或 DLL 卸载逻辑。

## UI 线程退出辅助实验

只创建、填充、销毁列表，不运行真实桌面移动；比较三轮 UI 循环在主线程完成和每次在新 UI 线程完成后退出。三个进程样本：

| 样本 | 同线程 KiB | UI 线程退出 KiB |
|---|---:|---:|
| 1 | 3764 | 3668 |
| 2 | 3752 | 3628 |
| 3 | 3732 | 3644 |

中位数约减少 108 KiB。它不是完整 App 的绝对占用，且未清除约 MiB 级的图标状态；为此重新引入跨线程 UI、消息与清单同步，不值得，未采用。

## 已实现隐藏交接

用户明确选择允许隐藏时短暂交接。隐藏后启动同一个 exe 的干净后台实例；它先准备监视，取得单实例锁并发出 ready。旧实例发出 commit 后退出且不还原，新实例补扫交接期间新增文件，继续自动收纳。稳态仍只有一个应用进程，编号会变化。

- 只继承两个匿名事件句柄，不继承任意文件/目录/互斥锁句柄。
- 内部恢复参数须匹配有效父窗口、属性中的事件句柄、父进程号及相同 exe 路径。无效请求不能跳过异常恢复。
- commit 前继任者不处理整理或还原；启动失败/超时则取消未提交实例，旧实例重拿锁并恢复监视。
- 父实例让锁后崩溃时，已准备且持锁的新实例继续接管。
- 确认后关闭继承事件和旧进程句柄，避免长期持有旧实例资源。
- 正常再次右键、还原后退出及恢复失败留界面的行为保持不变。

## 端到端内存对照

真实 GUI 测试入口、1000 个合成 txt 文件，各模式三轮交替运行，取专用内存中位数。两个模式使用相同的新代码及引用修复；基线仅在测试构建中关闭交接。每次采样前等待 1.5 秒。

| 状态 | 不交接 KiB | 隐藏交接 KiB |
|---|---:|---:|
| 列表打开 | 4436 | 4448 |
| 隐藏后 | 4524 | 1452 |
| 隐藏后再自动收纳一个新文件 | 4040 | 1616 |

隐藏后减少约 68%，继续自动收纳后的中位数减少约 60%。各稳态应用均无子进程。自动收纳样本存在波动，交接模式中一个样本为 3104 KiB；不能把 1.42–1.58 MiB 当成任何负载下的上限。原始数据：build/hidden-research/handoff-results.csv。原先内存探针直接调用 App 不运行真实主循环，不能测进程交接，因此改为测试控制器测量独立 GUI 进程。

图标引用修复独立重复三轮的隐藏后中位数为基线 4600 KiB、修复 4292 KiB，样本区间有重叠，不能把差额当成可靠的缓存释放量。核心收益来自干净实例接管。
