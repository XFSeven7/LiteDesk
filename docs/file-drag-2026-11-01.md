# 双向拖拽与多选验收（2026-11-01）

实现基于 Windows ListView 和 OLE/Shell，不引入第三方依赖。拖入仅接受当前用户桌面直属的文件和文件夹，可多选；拖到文件夹行仍作为顶层项目收纳。拖出只协商移动，取消不移动，同名不覆盖。

拖出前持久化源文件身份（卷、文件编号及创建时间），完成后保留仍在桌面的身份。自动收纳读取该状态并跳过对应项目，隐藏时干净实例读取相同状态；手动一键整理或刷新取消豁免，还原成功清除。相同名字的新文件不会继承原文件豁免。所有拖拽资源随窗口释放，隐藏继任者不初始化 OLE 界面。

选择支持空白处鼠标框选、Ctrl 点选增减、Shift 连选和当前列表 Ctrl+A；拖动任一选中项移动整组。刷新按路径保留选择、焦点和 Shift 锚点；Shell 右键菜单使用当前组选中项。
