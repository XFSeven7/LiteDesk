# LiteDesk

Windows 10/11 轻量桌面整理工具（C++ / Win32）。托盘一键整理桌面：非应用项移入**与桌面同卷**的 `X:\LiteDesk\Parked`（`X` 为桌面所在盘），在一个悬浮窗内左右分栏展示（左文件夹、右文件，中间可拖分割条）；`.exe` / `.lnk` 等应用项留在桌面。清单与日志仍在 `%AppData%\LiteDesk`。

## 环境

- Windows 10/11 x64
- Visual Studio 2022（含「使用 C++ 的桌面开发」）
- CMake 3.20+

## 构建

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

产物：

- `build\Release\LiteDesk.exe` — 主程序（GUI / `WIN32` 子系统，链接 `comctl32` `shell32` `ole32`）
- `build\Release\LiteDeskTests.exe` — 控制台单元测试

## 自检（自动化）

```powershell
cmake --build build --config Release --target LiteDeskTests
.\build\Release\LiteDeskTests.exe
```

退出码应为 `0`。

## 首次运行

1. 运行 `LiteDesk.exe`（建议 Release 构建）。系统托盘出现 LiteDesk 图标；整理悬浮窗默认隐藏。
2. 再次双击 exe 会因单实例互斥而直接退出（已有实例在运行）。
3. 在托盘图标上**右键**：**一键整理** / **还原桌面** / **显示/隐藏列表窗** / **退出**。
4. 整理后可在列表窗空白处右键：刷新（重新扫描并收纳新项）、还原桌面、隐藏列表。

## 数据目录（`%AppData%\LiteDesk`）

| 路径 | 说明 |
|------|------|
| `X:\LiteDesk\Parked\` | 整理期间从桌面移入的文件/文件夹（与桌面同盘；同卷移动，避免跨盘文件夹失败） |
| `manifest.json` | 收纳记录（桌面原名 ↔ Parked 路径） |
| `session.flag` | 整理会话标记；异常退出时下次启动会尝试自动还原 |
| `logs\` | 运行日志 |
| `ui.ini` | 悬浮窗位置与分割条比例 |

**如何还原桌面**

- 托盘 **还原桌面**，或 **退出**（退出前会先尝试还原）。
- 若程序被强杀或崩溃：再次启动 LiteDesk 会检测 `session.flag` 并自动执行还原。
- 还原时若桌面已有同名项，会自动加后缀 ` (1)`、` (2)` …，不覆盖已有文件。
- 还原失败项会留在 `manifest.json`，下次启动或再次点「还原桌面」会重试。

## v1 已知限制

- 不注册 Shell 扩展；不支持拖拽到列表、多屏独立布局、覆盖已有桌面文件。
- 托盘为系统默认图标；仅监视当前用户桌面（不含公共桌面）。
- 整理过程中正在下载/占用的文件可能收纳失败，需等文件就绪后通过空白处「刷新」或等待监视自动重试。
- 跨盘移动依赖 `MoveFileEx`；部分环境可能失败并记入日志（见 `park_restore` 测试）。
- **会话内 300ms 自动收纳**：整理后桌面一有变化，约 300ms 防抖后即自动 park 非应用项，可能打断「新建后重命名」或浏览器下载（临时文件/重命名中的文件被移走）。需要时先「还原桌面」再操作。
- **OneDrive 重定向桌面**：桌面位于 OneDrive 文件夹时，移动会触发同步；同步占用、「仅在线」占位文件可能导致收纳/还原失败或变慢，建议暂停同步时使用，或避免整理占位文件。
- **暂存位置**：`Parked` 放在桌面所在卷根下的 `LiteDesk\Parked`（例如桌面在 `G:\Desktop` 则为 `G:\LiteDesk\Parked`）。若该卷无法创建目录，会回退到 `%AppData%\LiteDesk\Parked`（跨卷时文件夹仍可能失败）。
- 隐藏/系统属性的桌面项（及 `desktop.ini`）不会被收纳。

## 手工验收清单（spec §7）

在**测试账户或已备份的桌面**上逐项勾选：

- [ ] **§7.1 一键整理**：桌面仅剩应用项（`.exe`、`.lnk` 等）；悬浮窗左栏为文件夹、右栏为文件。
- [ ] **§7.2 还原 / 退出**：「还原桌面」或「退出」后桌面恢复原状；`Parked\` 为空；无 `session.flag`。
- [ ] **§7.3 崩溃恢复**：整理完成后在任务管理器中结束 `LiteDesk.exe`，再次启动应自动恢复桌面。
- [ ] **§7.4 整理中新增项**：已整理状态下在桌面新建文件/文件夹，应被自动收纳并出现在列表中。
- [ ] **§7.5 还原冲突后缀**：还原时桌面若已有同名项，Parked 中的项应以 ` (1)` 等形式还原，不覆盖原文件。

可选：空闲时在任务管理器中观察 LiteDesk 内存占用（架构目标约 ~2MB，非硬门禁）。
