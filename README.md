# LiteDesk

Windows 10/11 轻量桌面整理工具（C++ / Win32）。托盘或桌面右键一键整理：非应用项移入**与桌面同卷**的 `X:\LiteDesk\Parked`（`X` 为桌面所在盘），在半透明悬浮窗内左右分栏展示（左文件夹、右文件，可拖分割条）；`.exe` / `.lnk` 等应用项留在桌面。清单与日志在 `%AppData%\LiteDesk`。

## 环境

- Windows 10/11 x64
- Visual Studio 2022（含「使用 C++ 的桌面开发」）
- CMake 3.20+

## 构建

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

产物：

- `build\Release\LiteDesk.exe` — 主程序（GUI / `WIN32`；`comctl32` / `uxtheme` 延迟加载）
- `build\Release\LiteDeskTests.exe` — 控制台单元测试

## 自检（自动化）

```powershell
cmake --build build --config Release --target LiteDeskTests
.\build\Release\LiteDeskTests.exe
```

退出码应为 `0`。

## 用法

1. 运行 `LiteDesk.exe`。托盘出现图标；**空闲不建悬浮窗**（更省内存），整理时再创建。
2. 再次启动 exe 若已在运行：带 `--organize` / `--restore` 会转发给已有实例；否则直接退出（单实例）。
3. **托盘**：双击 = 一键整理；右键 = **一键整理** / **退出**（退出前还原桌面）。
4. **桌面空白处右键**：「一键整理」（已注册到当前用户；Win11 完整右键菜单可见）。
5. 整理后悬浮窗空白处右键：刷新、还原桌面、隐藏。列表支持就地重命名；壳菜单删除后会同步 manifest。
6. 整理时会冻结桌面重绘、收拢图标空位，并把回收站钉到 FolderView 客户区右下角。

## 数据目录

| 路径 | 说明 |
|------|------|
| `X:\LiteDesk\Parked\` | 整理期间从桌面移入的文件/文件夹（与桌面同盘） |
| `%AppData%\LiteDesk\manifest.json` | 收纳记录（桌面原名 ↔ Parked 路径） |
| `%AppData%\LiteDesk\session.flag` | 整理会话标记；异常退出时下次启动尝试自动还原 |
| `%AppData%\LiteDesk\logs\` | 运行日志 |
| `%AppData%\LiteDesk\ui.ini` | 悬浮窗位置与分割条 |

**如何还原桌面**

- 悬浮窗空白菜单 **还原桌面**，或托盘 **退出**（退出前会先还原）。
- 若被强杀/崩溃：再次启动会检测 `session.flag` 并自动还原。
- 还原时桌面已有同名项会加后缀 ` (1)`、` (2)` …，不覆盖。
- 还原失败项留在 `manifest.json`，下次启动或再还原时重试。

## 内存（实测量级，非硬门禁）

策略：**空闲尽量瘦、用时再涨**（懒建悬浮窗 + `comctl32`/`uxtheme` 延迟加载；隐藏/还原后拆窗并收回工作集）。

| 状态 | 工作集（约） | 专用（约） |
|------|-------------|-----------|
| 冷启动空闲（仅托盘） | 0.2 MB | 1.7 MB |
| 整理中（悬浮窗打开） | 14 MB | 4 MB |
| 还原后空闲 | 0.2 MB | 4 MB（`comctl32` 用过后系统常卸不掉） |

## v1 已知限制

- 不注册 Shell 扩展；不支持拖拽到列表、多屏独立布局、覆盖已有桌面文件。
- 仅监视当前用户桌面（不含公共桌面）。
- 整理中正在下载/占用的文件可能收纳失败，需等就绪后「刷新」或等监视自动重试。
- **会话内 300ms 自动收纳**：整理后桌面一有变化约 300ms 防抖后自动 park，可能打断「新建后重命名」或浏览器下载。需要时先还原再操作。
- **OneDrive 重定向桌面**：移动会触发同步；「仅在线」占位可能导致失败或变慢。
- **暂存位置**：`Parked` 在桌面所在卷 `LiteDesk\Parked`；无法创建时回退 `%AppData%\LiteDesk\Parked`（跨卷时文件夹仍可能失败）。
- 隐藏/系统属性桌面项与 `desktop.ini` 不会被收纳。

## 手工验收清单

在**测试账户或已备份的桌面**上逐项勾选：

- [ ] **一键整理**：桌面仅剩应用项；悬浮窗左栏文件夹、右栏文件。
- [ ] **还原 / 退出**：还原或退出后桌面恢复；`Parked\` 为空；无 `session.flag`。
- [ ] **崩溃恢复**：整理后强杀进程，再次启动应自动恢复桌面。
- [ ] **整理中新增项**：已整理状态下新建文件/文件夹，应被自动收纳并进列表。
- [ ] **还原冲突后缀**：桌面已有同名项时，以 ` (1)` 等形式还原且不覆盖。
- [ ] **列表同步**：在悬浮窗用壳菜单删除项后，列表与 manifest 应同步去掉该项。
- [ ] **就地重命名**：慢双击或右键重命名列表项，Parked 与 manifest 一并更新。
