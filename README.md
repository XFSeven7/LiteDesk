# LiteDesk

我自己用的一个 Windows 小工具。桌面上一堆文件、文件夹混在图标里，看着烦，就想一键把它们先收走，只留程序和快捷方式。

顺便加了一组窗口吸附快捷键，平时把窗口贴到半屏、四角，不用来回拖。

系统是 Windows 10 / 11 64 位。发布页里的 `LiteDesk.exe` 双击就能用，不用另装运行库：

https://github.com/XFSeven7/LiteDesk/releases

## 平时怎么用

双击运行后会在托盘里常驻，并弹一句「已在后台运行」。不整理的时候它就待着，任务管理器里大概 2MB 出头。

桌面空白处右键，选「一键整理」（Windows 11 要在「显示更多选项」里）。程序和快捷方式留在桌面，其余文件、文件夹收进悬浮窗：左边文件夹，右边文件。窗口默认出现在屏幕右上角，拖走之后会记住位置。

整理过的桌面会把剩下的图标从左上角排紧，回收站放在右下角。

悬浮窗里可以：

- 空白处右键：刷新、还原桌面、隐藏
- 慢双击改名，右键也有系统菜单
- 从桌面把文件拖进去，或从窗口里拖回桌面
- 可以多选（拉框、Ctrl、Shift、Ctrl+A）

整理期间，新丢到桌面上的东西过一小会儿也会被收进去。如果正在下载、或者刚新建还没改完名，可能会被提前收走，这时先还原再操作就行。

还原在悬浮窗空白处右键「还原桌面」。文件回到原来的地方，托盘程序还在，快捷键继续能用。真要退出，在托盘图标上右键「退出」，退出时也会把桌面还原回去。

要是程序被强行关掉，下次打开会尽量把没收完的东西放回来。同名的不会覆盖，会变成 `名字 (1)` 这种。

## 窗口快捷键

程序开着就能用，修饰键是 **Ctrl+Shift**。作用在当前这个窗口上，贴的是它所在屏幕、避开任务栏的那一块。

| 按键 | 效果 |
|---|---|
| ← → ↑ ↓ | 左 / 右 / 上 / 下半屏 |
| U I J K | 左上 / 右上 / 左下 / 右下 |
| D F G | 左 1/3、中间 1/3、右 1/3 |
| E T | 左 2/3、右 2/3 |
| Enter | 铺满 |
| Backspace | 回到吸附前的大小和位置 |

这组键是全局的。LiteDesk 开着的时候，编辑器里用 Ctrl+Shift 加左右方向键按词选字会失效。

## 文件实际放哪

收起来的东西不在回收站，而在桌面所在盘的 `LiteDesk\Parked`，比如桌面在 `G:\Desktop`，就是 `G:\LiteDesk\Parked`。和桌面同一块盘，搬家比较快。清单和日志在 `%AppData%\LiteDesk`。

隐藏文件、`desktop.ini` 不会被收。桌面如果被 OneDrive 接管，移动时会跟着同步，有时会慢，或者失败。

## 自己编译

装好 Visual Studio 2022 的 C++ 桌面开发，再加 CMake。在项目目录里：

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

生成的程序在 `build\Release\LiteDesk.exe`。
